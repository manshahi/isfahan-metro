# 🚈 مسیریاب و زمان‌بندی آنلاین مترو اصفهان (Isfahan Metro PWA)

یک اپلیکیشن تحت وب پیشرونده (**PWA**) سبک، سریع و قابلیت نصب روی موبایل/دسکتاپ برای محاسبه زمان‌بندی و مسیریابی قطار شهری اصفهان (خط ۱).

این برنامه با استفاده از اطلاعات رسمی ایستگاه‌ها و جدول زمان‌بندی حرکت قطارها، زمان حرکت قطار بعدی از مبدا، زمان تقریبی رسیدن به مقصد و جدول کامل حرکت‌های روزانه را به تفکیک **روزهای عادی** و **روزهای جمعه و تعطیل** محاسبه می‌کند.

---

## ✨ ویژگی‌های کلیدی (Features)

- 📱 **پشتیبانی کامل از PWA:** قابلیت نصب روی سیستم‌عامل‌های Android، iOS و Windows بدون نیاز به استور.
- ⚡ **کارکرد آفلاین (Offline-First):** ذخیره‌سازی داده‌ها و کدهای فرانت‌اند با استفاده از Service Worker جهت دسترسی بدون اینترنت.
- 📅 **تفکیک برنامه زمان‌بندی:** تشخیص هوشمند روزهای عادی (شنبه تا پنج‌شنبه) و روزهای جمعه/تعطیل رسمی.
- ⏱️ **محاسبه هوشمند زمان:** محاسبه زمان دقیق حرکت قطار بعدی بر اساس زمان فعلی یا زمان انتخابی کاربر.
- 🗺️ **مسیریابی پویا:** محاسبه تعداد ایستگاه‌های بین راه و تخمین زمان سفر داخل قطار بر اساس فاصله ایستگاه‌ها.
- 🔍 **استخراج هوشمند داده‌ها (OCR):** دارای اسکریپت پایتون خودکار برای استخراج و بروزرسانی زمان‌بندی از روی بنرها/تصاویر رسمی وب‌سایت مترو اصفهان.

---

## 🛠️ تکنولوژی‌های استفاده‌شده (Tech Stack)

### Frontend & PWA
- **HTML5 & CSS3:** طراحی مدرن، واکنش‌گرا (Responsive) و مطابق با فونت و استایل استاندارد فارسی.
- **Vanilla JavaScript (ES6+):** بدون وابسته بودن به فریم‌ورک‌های سنگین برای بارگذاری فوق‌العاده سریع.
- **Web App Manifest & Service Worker (`sw.js`):** مدیریت کش (Cache) و قابلیت نصب PWA.

### Backend & Data Scraper (Python)
- **Python 3.x**
- **EasyOCR & OpenCV:** پردازش تصویر و تشخیص متن/اعداد از روی بنرهای جدول زمان‌بندی.
- **BeautifulSoup4 & Requests:** دریافت و پایش متادیتا از وب‌سایت رسمی مترو اصفهان.
